## How we choose what to build

1. **One thing at a time.** We would rather finish one project well than start five halfway.
2. **Own the core.** Core systems are written in Rust and run on infrastructure we control.
3. **Premium and secure.** If a project cannot meet that bar, it waits.
4. **Clear lines.** There are things we will not build. Read [What we will not build](/news/principles).
