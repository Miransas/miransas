# Security Policy

Security is a core part of how we build at Miransas. If you believe you have found a vulnerability in anything we run, please tell us. We take every report seriously.

## How to report

Send your report to **contact@miransas.com** with the subject line **"Security"**.

Please include:

1. What you found and where (URL, product, or repository).
2. Steps to reproduce it.
3. What you think the impact is.
4. Any proof of concept, screenshots or logs that help.

Please do **not** open a public GitHub issue for a security problem.

## What to expect

We are a small team. We will read your report, confirm it, and work on a fix. We cannot promise a fixed response time, but security reports come before everything else.

## Please do

- Give us reasonable time to fix the issue before you share details publicly.
- Test only with your own accounts and data.
- Stop and tell us if you reach someone else's data by accident.

## Please do not

- Access, change or delete data that is not yours.
- Run denial-of-service, spam or social-engineering attacks against us, our users or our team.
- Use a vulnerability for anything beyond proving that it exists.

## Scope

This policy covers the Miransas website, the products and services we run, and the repositories under [github.com/Miransas](https://github.com/Miransas). Third-party services we use have their own policies.

## Rewards

We do not run a bug bounty program. We are happy to credit you publicly for a valid report if you would like that.

## Supported versions

We fix security issues in the latest version of each product.
